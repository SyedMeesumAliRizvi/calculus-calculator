# Calculus & Analytical Geometry Calculator

An interactive, menu-driven Python application designed to handle advanced calculus computations symbolically and eliminate manual calculation errors.

## ✨ Key Features
- **Limits Evaluation:** Computes one-sided and two-sided limits approaching finite values or infinity.
- **Symbolic Differentiation:** Calculates first-order and higher-order derivatives for complex functions.
- **Integration Engine:** Computes both definite and indefinite integrals effortlessly.
- **Taylor Series Expansion:** Generates series expansions for functions around specified points up to custom intervals.
- **Area Under Curve:** Uses definite integration to compute the exact geometric area under a specified function boundary.

## 🛠️ Tech Stack & Libraries
- **Language:** Python
- **Core Library:** SymPy (Symbolic Mathematics Library)
